# A. SKY SUNMI Printer Bridge — APK-ready project

Target device: SUNMI V2 Pro / V2_PRO-ST, Android 7.1.2, firmware 112.

## What it does
- Native Android WebView wrapper for the A. SKY Services website.
- Uses SUNMI's native inbuilt printer service instead of browser `window.print()`.
- Includes CONNECT and TEST PRINT controls.
- Exposes JavaScript bridge:
  - `window.SunmiPrinter.printText(text)`
  - `window.SunmiPrinter.getStatus()`
  - `window.SunmiPrinter.connect()`
- Target SDK 25 to remain appropriate for the old Android 7.1.2 device.
- Uses SUNMI `printerlibrary:1.0.18`.

## Build
Open this folder in Android Studio. Allow Gradle to download dependencies, then Build > Build APK(s).

The resulting APK is normally under:
`app/build/outputs/apk/debug/app-debug.apk`

For release, configure a signing key and build a signed APK.

## Website integration
The existing A. SKY Services plugin can call the native bridge when it exists, and keep browser printing as fallback:

```js
function askySunmiPrint(text) {
  if (window.SunmiPrinter && typeof window.SunmiPrinter.printText === 'function') {
    window.SunmiPrinter.printText(text);
    return true;
  }
  return false;
}
```

This bridge is intentionally text-first. For the exact existing bill/receipt layout, the next integration step should send the final receipt text/bitmap generated by the plugin to this bridge, while preserving the current browser/Bluetooth fallback.

## Important
The APK must be built/signed before installation. This project is source-level APK-ready; it is not a precompiled APK.
